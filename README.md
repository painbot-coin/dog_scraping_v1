# Dog listings scraper (v1)

Selenium crawler for Dogs Trust rehoming pages. It expands the public list, opens each dog, and stores name, status, location, age, sex, breed, intro, and photo.

## What is in here

- Chrome/Selenium crawler
- CSV export
- Optional MySQL + WordPress media upload (configure via environment variables; do not commit credentials)

## Stack

Python, Selenium, MySQL, WordPress REST API
